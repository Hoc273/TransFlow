# Trang Hướng Dẫn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng trang /guide public (sidebar + nội dung Markdown song ngữ) và trang /platform/guides cho Platform Super Admin CRUD, với 3 điểm vào (landing navbar, AvatarMenu trên Cài đặt, PlatformShell).

**Architecture:** Module backend `guide` mới (public GET permitAll + admin CRUD qua requirePlatformAdmin); frontend 2 lazy routes + api/hooks/types + namespace i18n `guide`; Markdown render bằng react-markdown.

**Tech Stack:** Spring Boot 3 (JPA, Flyway SQL migration), React 19 + react-router 7 + react-query 5 + react-markdown/remark-gfm, i18next vi/en, vitest.

**Spec:** docs/superpowers/specs/2026-09-23-guide-design.md

## Global Constraints

- Mọi response backend dùng envelope `ApiResponse<T>` (code/message/data).
- Mọi write admin phải gọi `PlatformAdminAccessService.requirePlatformAdmin(userId)` đầu service.
- Public API chỉ trả PUBLISHED; slug unique toàn bảng, pattern `^[a-z0-9-]+$`.
- Không dùng `dangerouslySetInnerHTML`; Markdown không cho HTML thô (không rehype-raw).
- bilingual vi/en cho mọi title/content/excerpt; UI fallback vi.
- YAGNI: không version history, comment, view-count, upload ảnh server phase 1.

// GuideCategory.java
package com.app.modules.guide.entity;
import jakarta.persistence.*; import lombok.*; import org.hibernate.annotations.UuidGenerator;
import java.time.Instant; import java.util.UUID;
@Entity @Table(name = "guide_categories") @Getter @Setter @NoArgsConstructor
public class GuideCategory {
    @Id @UuidGenerator @Column(nullable = false, updatable = false) private UUID id;
    @Column(nullable = false, unique = true, length = 120) private String slug;
    @Column(name = "title_vi", nullable = false, length = 200) private String titleVi;
    @Column(name = "title_en", nullable = false, length = 200) private String titleEn;
    @Column(name = "order_index", nullable = false) private int orderIndex = 0;
    @Column(name = "is_published", nullable = false) private boolean published = true;
    @Column(name = "created_at", nullable = false, updatable = false) private Instant createdAt;
    @Column(name = "updated_at", nullable = false) private Instant updatedAt;
    @PrePersist void prePersist() { Instant now = Instant.now(); createdAt = now; updatedAt = now; }
    @PreUpdate void preUpdate() { updatedAt = Instant.now(); }
}
